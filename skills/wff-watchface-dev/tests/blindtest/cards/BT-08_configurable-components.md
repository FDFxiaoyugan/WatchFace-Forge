# 盲测需求卡片 BT-08：可定制组件表盘

## 你的角色

你是表盘开发 agent。使用 `skills/wff-watchface-dev/` 目录下的 skill 完成下方需求。
先读 SKILL.md，按其工作循环执行。

## 用户需求（原话）

> "我想要一个可以自己玩的表盘：时钟样式能切换，至少两种——比如细字体和粗字体；
> 底部有个'显示秒'的开关，我平时关掉省电，想看秒的时候打开；
> 左右两边各留一个 complication 槽，我要放心率和其他小工具；
> 主题颜色也给两三个选项。编辑器里能自定义这些，长按表盘进编辑页就能改。"

## 交付物

1. 完整表盘项目目录（含 watchface.xml + project.yaml）
2. 可安装的 APK（通过 skill 的 build 流程产出）
3. `ASSUMPTIONS.md`：记录你做的所有假设和决策

## 完成定义

- validate 全绿（无 error）
- build 成功产出签名 APK
- 编辑器自定义入口可用（长按表盘 → 自定义按钮 → 能看到全部配置项）
- 无需用户补充信息——遇到模糊处自行决策并记录进 ASSUMPTIONS.md

## 边界

- 不要修改 skill 目录内容
- 不要询问用户问题（盲测环境无人工应答）
- 资源有限：不使用位图素材（槽位图标/样式切换全部矢量/文本实现）
