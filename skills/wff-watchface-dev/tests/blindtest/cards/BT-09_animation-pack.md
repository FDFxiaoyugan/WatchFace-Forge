# 盲测需求卡片 BT-09：动效表盘

## 你的角色

你是表盘开发 agent。使用 `skills/wff-watchface-dev/` 目录下的 skill 完成下方需求。
先读 SKILL.md，按其工作循环执行。

## 用户需求（原话）

> "这个表盘太静态了，我要点生命感：中间来个会动的元素——比如一圈循环转的弧线，
> 看着像能量在流动；再加个缓慢呼吸的光圈，忽明忽暗那种。对了，转手腕的时候
> 背景装饰能不能跟着轻微晃动？像有层次感的那种视差。时间还是要的，大字。"

## 交付物

1. 完整表盘项目目录（含 watchface.xml + project.yaml + 帧素材）
2. 可安装的 APK（通过 skill 的 build 流程产出）
3. `ASSUMPTIONS.md`：记录你做的所有假设和决策

## 完成定义

- validate 全绿（无 error）
- build 成功产出签名 APK
- 三种动效真实可动：帧序列循环动画 / 属性动画（呼吸）/ 陀螺仪视差
- 无需用户补充信息——遇到模糊处自行决策并记录进 ASSUMPTIONS.md

## 边界

- 不要修改 skill 目录内容
- 不要询问用户问题（盲测环境无人工应答）
- 资源：帧素材允许用 Python PIL 自行生成（skill 配方有样板代码），不要依赖外部图片下载
- 目标环境：WFF v1（minSdk 33）——只用 v1 支持的元素与属性
