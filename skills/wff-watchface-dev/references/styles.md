# 表盘美学风格库（styles）——skill v0.6 设计层

> 技术正确性由 pitfalls/recipes 保证（XSD 合法 + 真机可渲染）；本文档保证**好看**。
> 选风格 → 抄 token → 套对应配方骨架 → 素材用配方里的 PIL 代码生成。

## 0. 通用设计法则（所有风格共用）

**450×450 圆盘布局网格**：
- **圆屏安全区 = 内接正方形**（对角线=画布直径）：450 画布内接矩形宽约 318，
  所有矩形元素四角须落在内接圆内（角点到圆心距离 < 225-10px 裕量）；
  "距边缘 40px" 只对水平中带成立，上下 1/3 区域必须按 √(r²-dy²) 收窄宽度
  （真机实证：S1 首版底部数据胶囊被圆边切割）
- 时间字号阶梯：主时间 84-120（占高 1/4~1/3）、副信息 16-26、标签 12-14
- 三分法：上 1/3 放强调元素（弧/标签）、中 1/3 放时间、下 1/3 放数据/装饰
- 视线动线：表盘是**瞥视**媒介（<2 秒读取）——一屏一个主信息，其余退层级

**配色铁律**：
- 底色永远深（OLED 省电 + 对比度）：#06-#12 亮度段的近黑；**纯黑省电选项**
  （#ff000000）是 AMOLED 的最佳 AOD 底色
- 主强调色全表盘**只出现 1-2 处**（时间或单一弧环），辅助色降饱和 40%
- 文字与底对比度 ≥ 7:1（WCAG AAA，小圆屏要更高）
- 8 位 ARGB 格式 `#ffRRGGBB`（R13 之前的老坑）

**字体层级**：SYNC_TO_DEVICE 家族；weight 阶梯只用 NORMAL/MEDIUM/BOLD 三档；
同屏字号档位 ≤ 3 个；**个性化字体 = 系统字 weight/width 变体**
（SYNC_TO_DEVICE 12 weight × 9 width，见 R61）；字距用空格分隔
（letterSpacing 是虚构属性，Text 只有 ellipsis/maxLines）。
**BitmapFonts 位图字模在 WOS6 全通道废弃（R61 真机实证，TimeText 与
PartText 通道均不渲染）——不要再用位图字体做任何表盘**。

## S1 · Material You（仿 Pixel Watch 官方风）

**一句话**：大胶囊时间块 + 单 seed 派生色板 + 圆角几何，"谷歌亲儿子"观感。

**设计 token**：

| 项 | 值 |
|---|---|
| 底色 | `#ff0E1512`（seed 青绿系的 surface-900） |
| 时间胶囊底 | `#ff2E6B5C`（secondary 深色块——位图字模白色协调所有主题） |
| 时间字 | 系统字 SYNC_TO_DEVICE weight=BOLD 白色（R61：位图字体已废弃） |
| 副信息 | `#ffA3C9BD`（surface 变体，on-surface-variant） |
| 数据胶囊 | secondary 色圆角块 + 白图标 + 亮色数值 |

**ColorConfiguration 6 主题**（长按表盘自定义切色）：Sage/Violet/Amber/Fern/Rose
+ **Mono 纯黑省电**（黑底/白胶囊/灰副字——AMOLED 用户刚需）。

**布局骨架**：时间胶囊 340×136 居中（水平中带安全）→ 日期行 → 底部双数据
胶囊（110×54，角点验算内接圆内：Δ=(±130,+127) → 距心 181<215 ✓）→ 每个数据
胶囊 = PartDraw 圆角块 + PartImage 白图标（脚印/闪电, PIL 几何手绘）+ PartText
数值。

**数据源对**：步数 `[STEP_COUNT]`；电池 `[BATTERY_PERCENT]`（**不是**
BATTERY_PERCENTAGE）；日期 `[DAY_OF_WEEK_S]+[MONTH]+[MONTH_DAY]` 格式
`%s %s.%s`（"周日 9.13"统一格式）。

## S2 · 极简 Mono（Essential/瑞士极简）

**一句话**：纯排版驱动——白/灰大字时间 + 小副行 + 单一强调，零装饰零素材。

**设计 token**：

| 项 | 值 |
|---|---|
| 底色 | `#ff000000` 纯黑（省电最佳） |
| 主时间 | `#ffF5F5F5` THIN **116**（小圆屏要占满中带，88 显小真机实证） |
| AMBIENT 时间 | `#ff9A9A9A` THIN 96（双层 TimeText 切换） |
| 副行 | `#ff8C8C8C` 26（周 + 月.日） |
| 强调 | 底部 60×6 圆角短线 `#ff7FDAC5`（全屏唯一彩色） |

**排版**：时间垂直中心偏上（y 132-332 大带），副行 y 352，强调线 y 402——
底部元素宽度按 √(225²-177²)≈139 半宽收窄。

## S3 · 暗色能量（Cyber/Tech 精修版）

**一句话**：多层辉光弧 + 呼吸 halo + 帧序列动效，BT-09 血统的视觉精修。

**设计 token**：

| 项 | 值 |
|---|---|
| 底色 | `#ff06090D` |
| 主弧 | `#ffC8FFF4`（亮白青, 最粗 9px, 弧长呼吸 ±40°） |
| 中弧 | `#ff2DE1C6` 反向转 |
| 内弧/心弧 | `#ff1A8F7A` / `#ff0F5C4E` 降饱和梯度 |
| 时间字 | `#ffE8FFF8` BOLD |

**素材配方**（PIL 三层辉光弧 + 整体 GaussianBlur 叠加 lighter）：
```python
# 每条弧三层描边: (core*2.6, α26) (core*1.6, α85) (core, α255) + 尾迹渐隐
# 全帧 blur(5) 后 ImageChops.lighter 叠回 → 柔光扩散
# 弧速必须 speed×45 ≡ 0 (mod 360): 8/-8/4/-4 ✓; 弧长 = base + amp·sin(帧相位)
```

**动效铁律**：WOS6 只渲染帧序列（R53/R54）；呼吸 halo 用 30 帧 alpha 烘帧
（R55）；多条弧差速反向（8/-8/4/-4）+ 弧长呼吸 = "能量流动"观感的关键。

## S4 · 拟物表冠（Analog Classic）

**一句话**：传统制表盘美学——刻度环 + 三针 + 金属质感，"正装表"。

**设计 token**：

| 项 | 值 |
|---|---|
| 表盘底 | 深色 `#ff0D0D0F` + 径向暗角（素材层做） |
| 时标 | 银白 `#ffE8E8E8` 棒状（12/3/6/9 加粗）+ 分钟点阵 |
| 指针 | 时/分针银色渐变 PNG、秒针 `#ffD4A857` 金色 + 配重尾 |
| 字体 | PartText 小日期窗（3 点位） |

素材：刻度环 PNG（PIL 循环画棒+点）、指针 PNG（旋转轴校验 alpha 质心）。
**指针资源质量决定档次**——粗针像玩具，细针+配重尾像正装表。

## S5 · 信息仪表盘（Data Dashboard）

**一句话**：多环数据可视化（步数/心率/电量）环绕中心时间，健康穿戴本命风格。

**设计 token**：

| 项 | 值 |
|---|---|
| 底色 | `#ff0A0C10` |
| 时间 | `#ffF0F4F6` BOLD 72px 居中 |
| 步数环 | `#ff7FDAC5`（220° 弧，[STEP_COUNT]/10000） |
| 心率环 | `#ffE87F7F`（左下 120° 弧，[HEART_RATE]） |
| 电量环 | `#ffE8C078`（右下 120° 弧，[BATTERY_PERCENT]） |
| 图标+数字 | 各环旁 14px 标签 |

**结构**：中心时间 + 环绕三弧（0°=12 点，弧缺口对准上方 12 点留呼吸感）。
进度弧动态性受 R53 限制（Transform 数据驱动在 WOS6 未实证）——稳妥做法：
PartImage 预渲染进度弧帧或 Arc 静态+数值 PartText。

## 风格 → 现有配方映射

| 风格 | 基础配方 | 追加模块 |
|---|---|---|
| S1 Material You | §1 数字 | ColorConfiguration 6 色（§3 颜色包）+ Font weight=BOLD（位图字已废弃，R61） |
| S2 极简 Mono | §1 数字 | 纯排版调优 + AMBIENT 双层 + 纯黑底 |
| S3 暗色能量 | §5 动效 | 辉光弧素材配方 + 呼吸帧序列 |
| S4 拟物表冠 | §2 三针 | 刻度环/指针素材配方 |
| S5 数据仪表盘 | §1 + §5 | 多数据源弧环布局 |

**选型建议**（用户提需求时）：
- 提到"谷歌/像素/Material/现代" → S1
- 提到"简单/干净/大字" → S2
- 提到"酷/科技/能量/赛博/发光" → S3
- 提到"经典/机械/正装/传统" → S4
- 提到"健康/数据/运动/多环" → S5
- 没提风格 → 默认 S2 或 S1（最安全的两个）
